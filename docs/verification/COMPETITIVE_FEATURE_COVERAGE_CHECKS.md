# Competitive Feature Coverage Checks

## Scope

Run after teacher authoring, activity conversion, template/game offer, printable, library, sharing, embedding, target-language, or competitive strategy changes.

## Checks

- Confirm `docs/COMPETITIVE_FEATURE_COVERAGE_MATRIX.md` reflects the latest strategic stance.
- Confirm `/teacher/intake` shows `Competitive feature coverage`.
- Confirm curated activity pathways remain the default answer to switch-template expectations.
- Confirm printable outputs are recorded as planned.
- Confirm private tenant library comes before public community sharing.
- Confirm public community sharing remains marked as a white-label risk until governance exists.
- Confirm Japanese-as-target-language remains separate from Japanese assist-language support.

## Verification Command

```powershell
npm run verify:foundation
```
