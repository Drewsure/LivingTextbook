# Game Completion Next Path Checks

Run after active game route, student progression, completion summary, activity hub, route helper, or scoring changes.

```powershell
npm run verify:foundation
```

Then verify:

- Active non-entry game routes show `Game complete path` and `Next Activity`.
- Before completion, the next-activity action is visually blocked and does not unlock progress.
- After completion, the card shows the earned deterministic reward amount and suggests the next reviewed activity.
- The card links to the curated activity hub and Training Academy without creating a broad template-switch panel.
- Support routes, support language, print, media, and Training Academy guidance cannot substitute for target-language game completion.
- The card is shared across pairing, selection, text-spelling, and speaking routes.
