# Printable Output Readiness Checks

## Scope

Run after printable, PDF, worksheet, homework, activity pathway, QR/audio bridge, teacher export, or text-puzzle changes.

## Checks

- Confirm `npm run verify:printables` passes.
- Confirm `/teacher/intake` shows `Printable output readiness`.
- Confirm vocabulary listening sheet and sentence practice worksheet are ready as browser-print previews.
- Confirm teacher answer key remains planned.
- Confirm Word Search and Crossword remain blocked.
- Confirm PDF export remains blocked until layout, QR/audio, version/rights, and export-policy gates exist.
- Confirm printables do not imply automatic Star Dust, mastery, or completion.
- Confirm printable QR/audio bridge remains part of the plan.
- Confirm `/print/demo-unit-1` and `/print/partner-demo-unit-1` are checked by active route verification.

## Verification Command

```powershell
npm run verify:foundation
```
