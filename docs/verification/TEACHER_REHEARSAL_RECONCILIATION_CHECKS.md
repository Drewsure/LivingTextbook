# Teacher Rehearsal Reconciliation Checks

- The teacher session passes expected tenant, package, and student-session
  identities into the local evidence panel.
- Mismatched local evidence is hidden and explained.
- A bound record shows the first-seen cross-route activity journey.
- Journey cards summarize starts, answer results, completion, mastery, and
  learning-audio request counts.
- The summary is read-only and cannot unlock games, mutate progression, award
  rewards, export, or create a classroom record.
- Raw audio, transcripts, support-language-only evidence, and hosted writes
  remain excluded.

Run:

```powershell
npm run verify:vertical-slice
```
