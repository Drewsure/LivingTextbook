# Build Session: Media Language Role Review Surface

Extended the teacher media-rights and media-library evidence previews with
explicit media language and target/assist/neutral role display. Upload-channel
readiness now names the same requirement, keeping policy-bound multilingual
media visible from intake review through package review.

The change remains review-only. It does not add upload, storage, release,
playlist, assignment, or progression behavior.

Recorded in ADR 0937 and decision register DR-1009.
