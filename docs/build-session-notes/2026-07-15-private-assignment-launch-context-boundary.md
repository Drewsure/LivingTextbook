# Build Session Note: Private Assignment Launch Context Boundary

Date: 2026-07-15

## Change

Added the controlled-practice launch context card to private assignment preview routes.

## Why

Private assignment links are useful for teacher sharing, but they should not imply live classroom launch, production student accounts, public sharing, or report export.
