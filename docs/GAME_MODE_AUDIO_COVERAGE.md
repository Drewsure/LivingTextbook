# Game Mode Audio Coverage

## Purpose

Every active student-facing game mode must be represented in the unit audio support plan. This prevents new routes from becoming readable-only experiences for young learners.

## Current Coverage

The MiniStar and sample publisher packages now declare audio cue coverage for:

- Flashcards
- Memory Match
- Quiz
- Sentence Builder
- Speak It

## Minimum Standard

Each active mode should have:

- vocabulary and/or sentence cues relevant to the game,
- at least one instruction cue,
- feedback cues where the game presents success, retry, or next-step text,
- tenant-owned or reviewed placeholder source metadata,
- no dependency on autoplay or cloud speech services.

## Boundary

This is content-package audio coverage, not a guarantee that recorded production audio files exist. Text-to-speech placeholders are acceptable for demo scaffolds, but production packages need tenant review and voice/source decisions.
