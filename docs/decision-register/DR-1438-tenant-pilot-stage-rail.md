# DR-1438: Tenant Pilot Stage Rail

Non-reference tenant pilot dashboards now show the same tenant-generic
six-stage path from publisher intake through teacher-led launch. The rail
makes the white-label product path visible without copying sample data,
inventing evidence, enabling writes, printing QR codes, or activating
students.

See ADR 1438 and
`apps/web/src/features/pilot/TenantPilotDashboardEmptyStatePanel.tsx`.
