# DR-1328: Publisher Delivery Operator Handoff

The live quarantine bridge now derives one ordered operator sequence from the
existing review records. It makes the next human action visible across source
and content evidence, packet capture, delivery and adapter selection,
release/QR authorization, package assembly/integrity readback, and teacher
rehearsal.

This is an operational projection only. It remains blocked and review-only;
the panel cannot write files, issue release receipts, print QR codes, activate
hosted persistence, or start students. See ADR 1329.
