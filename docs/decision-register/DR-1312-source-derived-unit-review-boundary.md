# DR-1312: Source-Derived Unit Review Boundary

Date: 2026-09-30
Status: Accepted

The supplied MiniStar curriculum DOCX now has a real, checksum-bound Unit 1
review record for `Genki Disco Warmup`. The review preserves the eight source
terms and paragraph provenance, but records that target sentence structures are
missing from the supplied source excerpt. The current greetings demo therefore
remains a clearly labeled rehearsal fixture rather than an implicit source
import.

This record is review-only. It cannot create a teacher draft, student payload,
package, route, assignment, QR target, media playlist, or release. Sentence
authoring, Japanese support review, audio/media rights, and human release
approval remain open gates. See ADR 1313.
