# DR-224: Private Assignment Launch Context Boundary

Date: 2026-07-15

## Decision

Private assignment routes must show controlled-practice launch context before assignment details.

## Rationale

Private assignment links are the future teacher sharing lane. The foundation build must keep them visibly separate from live classroom launches, production student accounts, public sharing, and real learner reporting.

## Standard

- Assignment routes must show `Controlled assignment practice`.
- Assignment routes must show `No live classroom launch`, `Target language unlocks progress`, and `No production student accounts`.
- Support language and media remain support-only. Target-language events remain the progression trigger.
- Private assignment previews do not enable live assignment persistence, report export, or public activity sharing.
