# DR-726: Label It Canonical Integration

**Date:** 2026-09-13  
**Status:** Accepted  
**Area:** Canonical game integration / pairing engine

## Decision

Label It joins the canonical DOM slices. Its reviewed image placeholder, label
selection, anchor placement, feedback, mastery, completion, audio, scoring,
tenant, launch, and replay evidence must flow through the shared platform
contracts.

## Consequences

- The pairing parent engine now has memory, matching, and image-aware reference
  paths.
- Teacher evidence can distinguish asset policy from label interaction audio.
- Future labelled diagrams and Phaser image skins must preserve the same
  completion and asset-release boundary.
- Frozen Z.ai/Phaser work remains isolated until separately mapped and
  approved.
