# DR-104: Teacher Monitor Media Engagement

## Decision

Teacher session monitors should show a dedicated media engagement section by media asset.

## Reason

Music and video are part of the Living Textbook package and teachers need visibility into usage. Media engagement must remain separate from mastery and Star Dust so it supports learning without becoming a progression bypass.

## Standard

- Media engagement is reported by asset.
- Starts, pauses, completions, and background media events are counted separately.
- Media engagement is report-only and cannot unlock games, award mastery, or replace target-language practice.
- Sample monitor events must reference real package media asset ids.
