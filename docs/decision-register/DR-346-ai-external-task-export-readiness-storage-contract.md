# DR-346: AI External Task Export Readiness Storage Contract

Date: 2026-08-02

## Decision

Persist AI external task export readiness gates as backend-neutral hosted and local records before export tooling exists.

## Why

The platform needs a clean future path for sending strict prototype tasks to outside builders without turning copy-ready previews into uncontrolled live work orders.

## Preserves

- Export channels.
- Readiness checks.
- Blocked export actions.
- Reviewer identity requirement.
- Evidence storage requirement.
- External repository policy requirement.
- Return-review intake requirement.
- Codex owner confirmation requirement.

## Blocks

- No task export.
- No prompt copy action.
- No repository issue creation.
- No archive download.
- No live handoff.
- No app file writes.
- No route creation.
- No scoring authority.
- No student-facing pathway.
- No support-language progress.
