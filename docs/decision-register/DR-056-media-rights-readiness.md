# DR-056: Media Rights Readiness Gate

Date: 2026-07-09

Status: accepted

## Decision

Add a media rights readiness gate to teacher/admin intake.

## Rationale

The Living Textbook product includes audio and video as core package material. Textbook partners need a practical way to distinguish demo placeholders, owned media, partner-provided media, unknown rights, game-background permission, and local/offline bundle permission.

## Consequences

- Media rights blockers are visible before pilot scheduling.
- Optional media does not block core games when fallback audio exists.
- Local/offline media permission stays explicit.
- Partner-provided media cannot silently become production content.
