# DR-129: Local Companion Navigation Link

## Decision

Add the sample publisher local companion preview route to the shared navigation.

## Reason

The closed/local companion path is a core white-label requirement. It should be discoverable from the app shell during review instead of only appearing in route verification and the intake matrix.

## Standard

- Shared navigation includes `Local Preview`.
- The link points to `/local/sample-publisher`.
- The route remains a planning preview, not an offline-ready installer.
