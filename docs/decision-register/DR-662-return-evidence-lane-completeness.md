# DR-662: Return Evidence Lane Completeness

Status: Accepted

Decision: Require audio, mobile/accessibility, and event/scoring checklist evidence together before the prototype-return proof lane can be ready.

Guardrails:

- Audio-only evidence cannot satisfy the combined proof lane.
- Missing evidence keeps Codex return review blocked.
- This is a review-derived status only; it cannot authorize import, route replacement, or assignment.
