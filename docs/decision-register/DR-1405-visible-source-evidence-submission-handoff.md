# DR-1405: Visible Source Evidence Submission Handoff

- **Decision:** Show the create-once source evidence request and the guarded
  metadata submission command together in the tenant-scoped requirements panel.
- **Reason:** Operators should not need to reconstruct the safe sequence from
  scattered documentation, while the credential must remain outside the UI
  payload and client routes.
- **Boundary:** This is review-only evidence capture. It does not upload raw
  files, assemble or release a package, print QR codes, activate persistence,
  or enable students.
- **Verification:** `verify-publisher-pilot-intake-kit`,
  `verify-publisher-source-preflight-evidence-submit`, foundation composition,
  typecheck, and production build when the Windows process state is healthy.
