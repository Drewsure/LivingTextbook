# DR-174: Collection Ownership Provenance Preview

## Decision

Show ownership provenance in the collection route before real collection inventory persistence exists.

## Rationale

The collection feature is central to student engagement. Teachers and future implementers need to see that ownership comes from accepted learning events and deterministic mastery rules, not random pressure loops or purchase-like states.

## Implications

- Collection routes show unlock source events and rule snapshots.
- Collection storage remains policy-gated.
- Route verification now checks the provenance preview text.

## Next

When persistence begins, map this preview shape to the collection inventory storage spec.
