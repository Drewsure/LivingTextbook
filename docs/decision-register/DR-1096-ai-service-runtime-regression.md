# DR-1096: AI Service Runtime Regression

- The AI service now has executable runtime coverage alongside static checks
  and typechecking.
- The harness proves pedagogical, language, evidence, cost, and no-dispatch
  boundaries against the actual compiled service.
- No model call, billing, generated package write, verifier submission, route
  write, playlist write, assignment activation, or support-language progression
  is enabled.

References: ADR 1096, Build session 1010, and the AI service runtime verifier.
