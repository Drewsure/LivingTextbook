# DR-1248: Local Package Teacher Evidence

- **Status:** Accepted
- **Decision:** Add a package-scoped teacher evidence route and require one
  stable package/unit launch identity across local front door, game, media, and
  teacher routes.
- **Reason:** A saleable closed companion must let a teacher review the real
  student journey, not only launch a collection of disconnected activities.
- **Boundary:** The route reads and records browser rehearsal evidence only.
  Hosted persistence, report export, student activation, QR mutation, and
  release promotion remain blocked.
- **Evidence required next:** Teacher-observed rehearsal on a real publisher
  package, device/browser evidence, school policy, retention/export decision,
  and a selected persistence provider for durable reporting.
- **References:** ADR 1248 and `verify-local-pilot-teacher-evidence-route.mjs`.
