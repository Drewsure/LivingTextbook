# DR-105: Publish Gate Media Reporting Obligation

## Decision

The package publish gate must block pilot release until media routes, bundle decisions, and support-only media reporting are reviewed.

## Reason

The platform now treats music and video as core white-label package content. Release gates must prevent a package from shipping with unreviewed media rights, unclear local/hosted delivery, or media engagement that could be mistaken for mastery.

## Standard

- Media gates require reviewed playlist routes and local/hosted bundle decisions.
- Media engagement reporting remains support-only.
- Media-only completion cannot unlock games, award mastery, or substitute for target-language practice.
- Teacher report policy must keep media engagement separate from mastery and reward totals.
