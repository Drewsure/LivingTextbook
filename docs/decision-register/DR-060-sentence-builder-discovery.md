# DR-060: Sentence Builder Route Discovery

Date: 2026-07-09

Status: accepted

## Decision

Expose Sentence Builder in route contracts, dashboard game sequence, and the unit game offer map.

## Rationale

A playable route should not remain hidden. Teachers, platform reviewers, and future agents need to see that Sentence Builder is part of the game sequence and offer model.

## Consequences

- Sentence Builder becomes discoverable.
- The game offer map now covers pairing, text-spelling, speaking, and future arcade offers.
- Route contracts stay aligned with implemented student routes.
