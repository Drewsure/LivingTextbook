# DR-114: Background Media Policy

## Decision

Background music, chants, and video/audio atmosphere are optional enrichment. They must be teacher-controlled, off by default unless reviewed, and lower priority than direct learning audio.

## Reason

Young learners need reliable tap-to-speak support for English text, instructions, choices, sentence tiles, and feedback. Background media can make games feel alive, but it can also mask pronunciation and create noise if it is treated as automatic.

## Standard

- Tap-to-speak English learning audio always has priority.
- Background media must pause, duck, or mute when required learning audio plays.
- Background media events are engagement context only.
- Background media cannot unlock Star Dust, mastery, games, or progression.
- Teacher/session settings control whether reviewed background media can run in a game.
