# DR-1332: Publisher Source-to-Package Evidence Bridge

The MiniStar Unit 1 DOCX now has a generic review-only bridge that binds its
source-derived review, extraction preview, extraction packet, and proposed
sentences to the remaining evidence lanes required for a saleable package.

The bridge explicitly separates extracted source terms from platform-authored
sentence candidates. It records missing teacher approval, English audio,
Japanese support review, multimedia rights, game verification, and release
evidence. It remains blocked and side-effect-free: no draft, package, QR,
persistence, or student use is enabled. See ADR 1333.
