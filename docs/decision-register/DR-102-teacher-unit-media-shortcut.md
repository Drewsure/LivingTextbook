# DR-102: Teacher Unit Media Shortcut

## Decision

Teacher launch pages should show a reviewed unit media shortcut when the launch package includes a playlist.

## Reason

Teachers need fast access to textbook-linked songs/videos before or during a lesson. The shortcut should be package-driven so it supports white-label tenants and does not hard-code MiniStar behavior.

## Standard

- The shortcut is derived from the content package playlist for the current unit.
- It opens the reviewed playlist route.
- It is support/media access only and does not imply student progression unlocks.
