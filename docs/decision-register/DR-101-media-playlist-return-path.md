# DR-101: Media Playlist Return Path

## Decision

Media playlist routes should include a package-aware return link to the correct student unit launch.

## Reason

Media is part of the unit experience, but it should not become a dead-end route or replace the game/progression path.

## Standard

- MiniStar media returns to the MiniStar demo unit launch.
- Sample publisher media returns to the sample publisher unit launch.
- Return paths are demo resolver behavior and should later come from persisted package/launch context.
