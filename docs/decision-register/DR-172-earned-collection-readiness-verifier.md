# DR-172: Earned Collection Readiness Verifier

## Decision

Add `npm run verify:collection` to the foundation gate.

## Rationale

The collection room will eventually attract premium visual and gamification work. The verifier protects the child-safe, earned, non-random reward model before polish expands.

## Implications

- `npm run verify:foundation` now includes collection checks.
- Reward categories and collection routes must stay visible and deterministic.
- Random pressure loops and paid gacha-like mechanics remain blocked.

## Next

Expand this verifier when collection persistence or avatar room editing is implemented.
