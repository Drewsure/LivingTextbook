# DR-1270: Live Review Decision Capture

**Status:** Accepted

**Decision:** Add a gated, tenant-scoped capture control for the immutable
quarantine source-review decision in the live publisher handoff.

**Reason:** A saleable pilot rehearsal needs an authorized human to record the
source-review checkpoint against the real publisher submission.

**Boundary:** One create-only metadata decision. No release approval, package
assembly, promotion, QR print authorization, hosted persistence, or student use.
