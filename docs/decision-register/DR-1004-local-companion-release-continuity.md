# DR-1004: Local Companion Release Continuity

Date: 2026-09-30
Status: Accepted

The local companion path now has a package-scoped continuity packet for
installer, device, update, migration, rollback, backup, restore, retention,
and operator handoff evidence. The packet is shown in the deployment
workbench and remains blocked from installation, update execution, recovery
execution, export, package writes, route mutation, and student promotion.

This makes the packaged textbook product requirement explicit without
claiming that the installer or local update system already exists. The pilot
acceptance matrix remains planning/review-only until real artifacts and human
publisher/school decisions are supplied.
