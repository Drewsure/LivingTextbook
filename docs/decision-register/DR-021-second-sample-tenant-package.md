# DR-021: Second Sample Tenant Package

Status: Accepted

Date: 2026-07-01

## Decision

Create a second sample tenant and partner-style content package as the next structural proof that Living Textbook is white-label, not a MiniStar-only application.

## Rationale

MiniStar gives the platform curriculum structure and a flagship use case, but a saleable product needs evidence that other textbook owners can bring their own brand, reward naming, unit content, media, QR paths, and package rules.

## Accepted Scope

- Add a sample publisher tenant.
- Add one reviewed PDF-style content package.
- Reuse the existing launch, Speak It, multimedia, progression, teacher launch, and microphone approval components.
- Add a visible partner demo route.
- Keep the first partner package narrow and manually reviewed.

## Deferred Scope

- Automated PDF import.
- Partner admin tools.
- Persistence.
- Closed/local app packaging.
- Commercial media asset management.
- Active AI Tutor or AI speech scoring.
