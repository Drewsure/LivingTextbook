# DR-1313: Source-Derived Authoring Proposal Boundary

Date: 2026-09-30
Status: Accepted

The MiniStar Unit 1 source-review workspace now exposes a review-only authoring
proposal with exactly two conservative candidate sentences derived from the
eight extracted command terms. The sentences are explicitly platform-authored,
not source-extracted, and cannot be assigned, released, routed, bundled, or
printed as QR destinations.

Teacher approval, English audio, hiragana-only Japanese support, media rights,
accessibility, package integrity, release, and student-assignment evidence
remain open. See ADR 1314.
