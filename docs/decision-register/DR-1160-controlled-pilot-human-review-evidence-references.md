# DR-1160: Controlled Pilot Human Review Evidence References

Decision: Require the controlled-pilot human-review packet to include every
authoritative record identity named by its fields.

- Validate all six references, including storage preflight and storage gate.
- Reject missing or substituted evidence IDs.
- Keep review, approval capture, release mutation, and launch side-effect free.

References: ADR 1160, Build session 1074, and
`scripts/verify-controlled-pilot-human-review-packet.mjs`.
