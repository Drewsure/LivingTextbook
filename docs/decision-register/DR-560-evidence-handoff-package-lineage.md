# DR-560: Evidence Handoff Package Lineage

Status: Accepted

See `docs/adr/0489-evidence-handoff-package-lineage.md`.

The review-only evidence handoff packet now carries unit-package readiness, payload validation, target-language audio coverage, assist-language script policy, and curated activity pathway evidence with a source route back to `/teacher/intake`. Export, signing, storage, publishing, and assignment activation remain blocked.
