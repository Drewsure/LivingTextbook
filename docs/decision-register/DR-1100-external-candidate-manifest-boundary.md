# DR-1100: External Candidate Manifest Boundary

- Frozen Z.ai/Phaser folders are source snapshots, not returned evidence
  packages.
- Candidate review requires an isolated `evidence/return-package.json`.
- Manifest identifiers, paths, artifact count, and blocked actions are
  bounded before evidence alignment or adjudication.
- No source copy, archive import, app patch, route replacement, scoring
  mutation, persistence ownership, promotion, or assignment is enabled.

References: ADR 1100, Build session 1014, FR-058, and the runtime behavior
regression.
