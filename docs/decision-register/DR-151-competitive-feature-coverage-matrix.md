# DR-151: Competitive Feature Coverage Matrix

## Decision

Maintain a competitive coverage matrix and admin review panel for Wordwall-style feature expectations.

## Rationale

The platform needs to know where it competes, where it differs, and where copying a competitor would create cost or governance problems. The owner agreed that curated teacher-offered pathways are preferred over unrestricted template switching, private tenant libraries should precede public community sharing, and printables/Japanese target-language expansion should be preserved as opportunities.

## Accepted Direction

- Add a repo-level competitive coverage matrix.
- Add a teacher/admin intake panel for coverage review.
- Mark public community sharing as a white-label risk, not v1 scope.
- Mark printable outputs as planned.
- Mark Japanese as target language as planned opportunity, distinct from Japanese assist language.

## Follow-Up

When teacher authoring begins, add a payload-to-activity compatibility matrix that names which activity outputs are valid, blocked, or teacher-review-only for each payload shape.
