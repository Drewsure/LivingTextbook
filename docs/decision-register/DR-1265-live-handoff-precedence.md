# DR-1265: Live Handoff Precedence

**Status:** Accepted

**Decision:** Show a real tenant quarantine handoff before static reference
package panels and label the reference panels as examples.

**Reason:** A saleable white-label pilot must never confuse sample readiness or
release artifacts with a publisher's actual package.

**Boundary:** This changes presentation order and provenance labeling only. It
does not enable package assembly, release, QR printing, persistence, or student
use.
