# DR-1322: Publisher Submission Review Handoff

Date: 2026-09-30  
Status: Accepted

The publisher intake manifest now has a derived review handoff. Every manifest
asset receives one tenant/package-bound evidence lane, with links to the
intake, evidence index, and evidence handoff routes.

The handoff is review-only. It does not accept files, export evidence, capture
signatures, promote assets, print QR codes, activate persistence, or expose
students to incomplete content. This keeps the publisher's next action clear
while preserving the quarantine and release-control boundaries.

See ADR 1323 and `verify:publisher-submission-review-handoff`.
