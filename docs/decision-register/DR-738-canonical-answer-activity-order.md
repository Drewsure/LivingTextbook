# DR-738: Canonical Answer Activity Order

**Date:** 2026-09-13  
**Status:** Accepted  
**Area:** Canonical game integration / event integrity

The shared canonical event validator now rejects answer submissions or results
that occur after mastery or completion. This closes the answer window before
the platform accepts the final result and is covered by the runtime harness.

Related ADR: `docs/adr/0666-canonical-answer-activity-order.md`.
