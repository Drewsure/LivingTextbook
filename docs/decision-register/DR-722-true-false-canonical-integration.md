# DR-722: True or False Canonical Integration

**Date:** 2026-09-13  
**Status:** Accepted  
**Area:** Canonical game integration / selection engine

## Decision

True or False joins the canonical DOM slices. Its binary prompt, visible card,
answer, mastery, completion, audio, scoring, tenant, launch, and replay
evidence must flow through the shared platform contracts.

## Consequences

- The selection parent engine now has assessment, binary review, and arcade
  reference slices.
- Teacher evidence can distinguish prompt/card/choice audio from answer
  results.
- Future Phaser selection skins must preserve the same event and scoring
  boundary.
- Frozen Z.ai/Phaser work remains isolated until separately mapped and
  approved.
