# DR-1148: Teacher Draft Persistence Storage Identity

Decision: Preserve exact storage-selection preflight and evidence-storage gate
identity through teacher-draft persistence implementation readiness.

- Require storage preflight and gate IDs on the teacher-draft handoff.
- Require blocked status and disallowed selection.
- Reconcile the IDs against provider comparison and pilot review readiness.
- Reject storage identity drift before future adapter work-order authorization.

References: ADR 1148, Build session 1062, DR-1147, and the teacher-draft
persistence implementation readiness behavior verifier.
