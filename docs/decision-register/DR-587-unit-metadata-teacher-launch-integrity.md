# DR-587: Unit Metadata And Teacher Launch Integrity

Status: Accepted

Decision: Require valid unit identity, theme/engine metadata, visual focus, and complete teacher launch copy before review.

Guardrails:

- Levels are 1-8 and module/unit numbers are positive integers.
- Theme, game mode, family, engine, avatar family, and character focus are required.
- Hook, activity, and review copy are required.
- Validation remains side-effect free.
