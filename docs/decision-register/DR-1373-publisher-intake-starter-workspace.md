# DR-1373: Publisher Intake Starter Workspace

**Decision:** Show the bounded source-manifest command and next preflight step
inside each tenant's publisher upload workspace.

**Why:** A saleable white-label intake needs a clear operator handoff without
turning navigation into an upload or publish shortcut.

**Boundary:** The panel creates no files, sends no requests, and does not prove
source ownership, rights, accessibility, review, package readiness, QR release,
persistence, or student use.

**Verification:** The web typecheck, active-route verification, and standards
integrity checks cover both the sample publisher and empty white-label tenant
workspaces.
