# DR-1266: Live Release and QR Closure Visibility

**Status:** Accepted

**Decision:** Show the live quarantine preview's manifest, release receipt, and
package-index identities alongside an explicit blocked closure order for
evidence, assembly, recovery, QR alias registration, and human print approval.

**Reason:** Publishers need a saleable-pilot path they can understand before
the platform is allowed to create or distribute a package.

**Boundary:** This is preview and evidence presentation only. It does not
create a manifest, package, receipt, QR alias, hosted persistence record, or
student-facing release.
