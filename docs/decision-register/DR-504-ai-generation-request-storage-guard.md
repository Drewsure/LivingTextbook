# DR-504: AI Generation Request Storage Guard

Status: Accepted

Decision: Teacher generator routes must show an AI generation request storage guard next to the disabled request builder.

Reason: A request-builder preview can look close to a real AI action. The platform needs a visible foundation gate that names durable request, cost, audio, compatibility, media rights, draft, and verifier records before any live AI generation workflow can exist.

Implication: The generator stays review-only. No live model dispatch, model billing, generator request submission, draft generation, verifier submission, package assembly, route creation, playlist creation, student assignment, or support-language progress trigger can be enabled from request setup.

Review Rule: `verify:ai-generator` and active route verification must require the request storage guard on tenant generator routes.
