# DR-628: Complete External Prototype Tenant Scope

Status: Accepted

Decision: Every external-prototype evidence and patch-review persistence record is tenant-scoped through one shared category list and explicit tenant key.

Coverage includes intake, return packages, integration plans, wrapper review, fixture/event/audio/mobile/scoring reports, readiness gates, Codex decisions, patch proposals, approvals, release locks, work orders, and change-set previews.

This remains a review-only backend contract. It does not authorize Z.ai import, Phaser promotion, app writes, route mutation, scoring changes, package promotion, or student assignment.
