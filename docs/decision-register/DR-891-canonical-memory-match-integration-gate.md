# DR-891: Canonical Memory Match Integration Gate

The active Pairing Memory Match wrapper and `/memory/[code]` route are the
canonical reference. The frozen MiniStar Phaser candidate is now represented
by one review-only gate joining its frozen provenance to wrapper, fixture,
event, audio, scoring, accessibility, and Codex decision evidence.

The gate remains blocked until every required lane is reviewed. It does not
import source, replace routes, grant Z.ai authority, or create assignments.
See ADR 0819 and
`docs/verification/CANONICAL_MEMORY_MATCH_INTEGRATION_GATE_CHECKS.md`.
