# DR-1129: Release-Control Evidence Reconciliation

The tenant-scoped release-control decision room now consumes the exact
composite evidence release binding used by release readiness. This prevents a
release summary from appearing more complete than the browser, privacy, and
tenant evidence chain behind it.

The route remains review-only. Publication, assignment activation, local
bundle release, student-ready status, hosted persistence, and QR mutation are
still blocked.
