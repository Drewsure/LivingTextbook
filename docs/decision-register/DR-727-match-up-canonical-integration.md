# DR-727: Match Up Canonical Integration

**Date:** 2026-09-13  
**Status:** Accepted  
**Area:** Canonical game integration / pairing engine

## Decision

Match Up joins the canonical DOM slices. Its listening prompts, word cards,
matching attempts, feedback, mastery, completion, audio, scoring, tenant,
launch, and replay evidence must flow through the shared platform contracts.

## Consequences

- The pairing parent engine now covers memory, visible matching, and image-aware
  reference paths.
- Teacher evidence can distinguish prompt audio, card audio, and match results.
- Future matching variants and Phaser pairing skins must preserve the same
  completion and scoring boundary.
- Frozen Z.ai/Phaser work remains isolated until separately mapped and
  approved.
