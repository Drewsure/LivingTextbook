# DR-100: Student Unit Media Shortcut

## Decision

Student launch pages should show a reviewed unit media shortcut when the content package includes a playlist.

## Reason

Music and video are part of the Living Textbook package. Students and teachers need a visible way to open unit media without treating media engagement as a game unlock or mastery substitute.

## Standard

- Unit media opens through the reviewed playlist route.
- Media support does not award Star Dust or unlock games by itself.
- Background media remains teacher-controlled and off by default when the package says so.
- The shortcut must remain package-driven and tenant-neutral.
