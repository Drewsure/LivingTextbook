# DR-610: Game Catalog Learner-Facing Metadata

Status: Accepted

Decision: Validate learner role, skill focus, summary, and explicit background-media capability for every game catalog item.

Rationale:

- Pathway review depends on understandable metadata as well as routing.
- Missing classifications or summaries can make a mode misleading.
- Centralized validation is cheaper than discovering omissions during integration.

Guardrails:

- Roles and skill focuses use the shared catalog values.
- Summaries are required.
- Media capability is explicit.
- No provider, storage, playback, release, assignment, or student-state side effect is introduced.
