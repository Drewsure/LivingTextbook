**Status:** Accepted

**Decision:** Record a lane-complete, review-only evidence attestation for the
publisher package attached to a live quarantine submission.

**Lanes:** Content, games, audio, video, images, fonts, accessibility, and
rights.

check. Assembly, promotion, release, QR printing, local delivery, hosted
persistence, and student use remain separate blocked gates.

rehearsal must pass, and foundation composition must execute the verifier.
