# DR-1234: Saleable Pilot Acceptance Matrix

## Decision

Adopt `docs/PILOT_ACCEPTANCE_MATRIX.md` as the completion record for the first
saleable white-label pilot.

## Scope

The matrix covers publisher source intake, reviewed multimedia/game package
delivery, QR print authorization, teacher-led/student-driven use, local
delivery, opt-in hosted persistence, white-label tenant separation, and frozen
external-game integration.

## Current State

The foundation and review path are strong, but the pilot is not yet saleable.
Real publisher source evidence, rights/media evidence, delivery selection,
school policy, durable persistence approval, QR print authorization, and final
release-control evidence remain open.

## Rule

Do not declare the pilot complete from route availability or green structural
checks alone. Close each matrix row with authoritative evidence and human
review before enabling package delivery or real learner data.
