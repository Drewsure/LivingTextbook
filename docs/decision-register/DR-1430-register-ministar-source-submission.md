# DR-1430: Register MiniStar Unit 1 Source Submission

The existing MiniStar curriculum DOCX is now staged as the first real,
external publisher-source submission. Its tenant, owner, language, support
language, and hybrid delivery declaration are recorded, while missing audio,
media, policy, rights, accessibility, scan, and QR evidence keep the source
preflight and saleability audit blocked. The source remains outside the
repository and cannot become student-facing by declaration alone.

See ADR 1430 and `docs/PUBLISHER_PILOT_INPUT_KIT.md`.
