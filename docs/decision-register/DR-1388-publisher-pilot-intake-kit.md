# DR-1388: Publisher Pilot Intake Kit

The first saleable pilot needs a real publisher handoff, not only sample
tenant data. A reusable intake kit now gives the publisher a safe metadata
brief and media folder structure for source, image, audio, video, transcript,
font, and background-media lanes.

The kit remains review-only. It does not prove rights, scan status,
accessibility, checksums, package readiness, QR release, persistence approval,
or student use. Those gates remain in the existing quarantine, evidence,
package, delivery, and release contracts.

This keeps the white-label product practical for a new publisher without
hard-coding MiniStar assumptions or creating a shortcut around human review.
