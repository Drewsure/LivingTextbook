# DR-1325: Live Publisher Submission Review Journey

Date: 2026-09-30  
Status: Accepted

The authorized quarantine handoff now derives a single live review journey
from the submitted source and current evidence records. It makes the next
publisher action visible across source review, multimedia/game evidence,
package review, delivery, release/QR, and teacher rehearsal.

All package assembly, promotion, QR printing, persistence activation, and
student use remain blocked. The journey is a projection of review metadata,
not a release decision. See ADR 1326 and
`verify:publisher-submission-live-review-journey`.
