# DR-053: Teacher Session Preflight Before Live Classroom Use

Date: 2026-07-09

Status: accepted

## Decision

Add a teacher session preflight gate above the detailed monitor.

## Rationale

The teacher monitor is becoming detailed enough that a short readiness summary is needed. Teachers and pilot reviewers should quickly see whether a session is safe, what only warns, and what still blocks classroom use.

## Consequences

- Demo monitoring remains available.
- Real classroom pilot use remains blocked by persistence and policy gaps.
- Report export remains policy-bound.
- Future live controls have a clearer gate to satisfy.
