# DR-1011: Tenant-Scoped Pilot Command Shell

Status: Accepted

Decision: A publisher without a package receives a tenant-scoped pilot command shell, while the populated Sample Publisher dashboard remains a reference-only tenant view.

Rationale:

- White-label saleability requires tenant ownership to remain visible from first contact through evidence review.
- Returning a new publisher to a sample dashboard risks cross-tenant evidence confusion.
- A small review-only shell provides continuity now without pretending that a pilot package or classroom launch exists.

Consequences:

- New tenants can navigate requirements, intake, evidence, and media review from one tenant-scoped command surface.
- Sample Publisher remains the populated demonstration tenant.
- Production approval, QR print, persistence, local delivery, and student launch remain blocked until tenant-owned evidence closes the acceptance matrix.
