# DR-1315: Tenant-Empty Private Library Boundary

Date: 2026-09-30
Status: Accepted

The tenant-scoped private library now resolves its own tenant shell and shows
an explicit empty state for new tenants. Reference Sample Publisher content is
not copied into other tenants. Public community sharing, cross-tenant remixing,
student-data copying, and unreviewed assignment remain blocked. See ADR 1316.
