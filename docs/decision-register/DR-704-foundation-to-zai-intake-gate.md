# DR-704: Foundation To Z.ai Intake Gate

**Status:** Accepted

## Decision

Open controlled intake for isolated Z.ai game prototypes now that the
foundation verification gate is green. The first approved repository is
`Drewsure/ministar-lab`.

## Guardrail

This is not integration approval. Direct source copies, route activation,
package promotion, scoring or reward changes, live storage writes, and student
assignment remain blocked until a real returned package passes Codex review.

## Evidence Required

The return must include an immutable source snapshot, shared JSON fixture,
event and deterministic-scoring replay, target-language audio coverage,
mobile/accessibility evidence, Phaser wrapper notes when applicable, and a
README covering dependencies, controls, rights, and known limits.

## Ownership

Codex retains architecture, schema, integration, and final-review authority.
Z.ai may build isolated candidates only within the approved prototype scope.
