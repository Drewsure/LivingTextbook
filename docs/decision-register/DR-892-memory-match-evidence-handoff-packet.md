# DR-892: Memory Match Evidence Handoff Packet

Decision: create a human-triggered, review-only evidence packet as the first
concrete Z.ai engagement point for the frozen Memory Match candidate.

The packet requires frozen provenance plus nine return artifacts: manifest,
reviewed fixture, canonical event replay, target-language audio report,
deterministic scoring replay, mobile/accessibility report, wrapper adapter
review, SHA-256 source manifest, and setup/limitations README.

Handoff-ready is not integration-ready. Direct source import, route
replacement, scene-owned scoring or persistence, package activation, reward
mutation, and student assignment remain blocked until Codex reviews the
evidence and records an explicit integration decision.

Related records: ADR 0820 and
`docs/verification/MEMORY_MATCH_EVIDENCE_HANDOFF_CHECKS.md`.
