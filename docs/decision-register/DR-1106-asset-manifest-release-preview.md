# DR-1106: Asset Manifest Release Preview

Decision: Reconcile validated asset evidence into provider-neutral, target-aware
manifest previews before choosing storage or promotion adapters.

- Targets are game-asset-manifest, media-manifest, and
  source-document-manifest.
- Previews expose rights, accessibility, target mapping, release-control, and
  persistence blockers.
- Evidence-ready means ready for release review only.
- Manifest writes, storage, downloads, promotion, playlist/game binding,
  assignments, and student-facing use remain blocked.

References: ADR 1106, Build session 1020, and the content intake verification
checks.
