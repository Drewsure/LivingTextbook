# DR-551: Pilot Readiness Dashboard

Status: Accepted

Decision: Add `/teacher/pilot` as the focused pilot-readiness command view for first partner, colleague, or school conversations.

Rationale:

- A saleable white-label product needs a simple way to explain demo readiness without overpromising classroom readiness.
- The foundation already has evidence routes; this dashboard makes the current go/no-go state readable.
- Pilot timing should be discussed through visible blockers, not optimism alone.

Guardrails:

- No classroom launch, real learner data, report export, policy acceptance, local package activation, offline-ready claim, premium AI Tutor activation, or Z.ai prototype intake request can happen here.
- The dashboard links to evidence routes and reuses existing readiness panels.
- `npm run verify:pilot` and active route verification protect the route.
