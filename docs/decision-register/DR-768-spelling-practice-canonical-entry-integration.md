# DR-768: Spelling Practice Canonical Entry Integration

Spelling Practice is now a canonical text-spelling activity in student and
front-door launch flows. Its reviewed target-language prompt audio,
instruction and feedback audio, deterministic letter-tile scoring, replay,
standard events, and shared completion gate are reused.

The current fixture supports English letter normalization. Japanese
script-aware spelling and segmentation remain a separately reviewed
target-language expansion and are not implied by this promotion.

See ADR 0696, operating note OW-049, and the canonical integration verifier.
