# DR-215: Teacher Dry-Run Rehearsal Preview

Date: 2026-07-15

## Decision

Add a teacher dry-run rehearsal preview to the teacher/admin intake surface.

## Rationale

The white-label platform needs a professional pre-classroom rehearsal path. A teacher should know exactly which routes, game/audio controls, media/support-language behavior, reports, and local fallback expectations to verify before children touch the package.

## Standard

- The rehearsal derives from the pilot launch checklist, evidence packet, and handoff package.
- It must show `No student launch action`, `Teacher-only rehearsal`, and `Dry-run evidence only`.
- It must state `Do not collect real learner data`.
- It cannot create assignments, store live progress, export reports, upload evidence, or mark a package pilot-ready.
