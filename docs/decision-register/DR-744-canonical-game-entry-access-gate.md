# DR-744: Canonical Game Entry Access Gate

The shared playable route shell no longer self-unlocks the current game mode
when a direct game URL is opened. Locked routes remain reviewable, but the
interactive game component is withheld until the supplied progression state
contains the mode. This restores the canonical teacher-led entry practice and
curated student progression contract while persistence is still under review.

The access gate applies equally to future Phaser wrappers. It prevents a
standalone scene or direct route visit from producing valid game completion,
mastery, Star Dust, reward, or teacher-report evidence. See ADR 0672.
