# DR-1376: Derived Game Evidence Lane

- Decision: Represent platform-generated game evidence separately from
  publisher-uploaded asset evidence.
- Scope: Publisher package evidence reconciliation and review-only intake.
- Date: 2026-10-01
- Status: Accepted

The game lane now carries derived record identities for the curated pathway,
canonical game integration, and package game-audio coverage. It remains
review-pending until evidence references and package gates are complete. No
derived record is a file, approval, package release, QR authorization,
persistence activation, or student-facing entitlement.
