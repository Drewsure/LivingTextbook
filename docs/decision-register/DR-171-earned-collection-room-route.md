# DR-171: Earned Collection Room Route

Decision: Add `/collection/[code]` as the first earned collection room scaffold.

Rationale: Student motivation needs visible ownership and progression. The foundation version should prove categories and unlock rules before premium visuals are added.

Implications:

- MiniStar and sample publisher each have active collection room routes.
- Reward categories now include room items and companion evolution markers in addition to badges, titles, cosmetics, and power-ups.
- The active route matrix grows from 33 to 35 checked routes.
- Collection remains deterministic and mastery-earned; no random pressure loop is introduced.

Next: Add premium visuals, avatar/room art, and mascot evolution only after the structural route and reward rules stay stable.
