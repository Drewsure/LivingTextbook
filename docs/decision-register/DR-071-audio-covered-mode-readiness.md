# DR-071: Audio-Covered Mode Readiness

## Decision

Expose audio-covered game mode counts and lists in package readiness and multimedia package review.

## Rationale

Audio-first learning is a hard requirement. As more routes become active, teacher/admin review must show whether each active mode has explicit package-level cue coverage.

## Consequences

- Package readiness now makes per-mode audio coverage visible.
- Missing audio-covered modes can block pilot readiness.
- Future game additions must update package audio coverage and readiness review together.

## Non-Goals

- Final recorded audio asset production.
- Autoplay policy changes.
- Speech scoring.
