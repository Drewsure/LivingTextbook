# DR-1427: Explicit Publisher Language And Delivery Choices

The intake kit now accepts explicit target-language and delivery-mode choices,
with English and hybrid retained only as reference defaults. Hosted persistence
requires a separate explicit opt-in and cannot be requested for closed-local
delivery. The kit remains review-only and cannot assemble, print, activate, or
assign a package.

See ADR 1427 and `docs/PUBLISHER_PILOT_INPUT_KIT.md`.
