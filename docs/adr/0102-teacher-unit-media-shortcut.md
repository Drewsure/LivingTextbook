# ADR 0102: Teacher Unit Media Shortcut

## Status

Accepted

## Context

Student launch pages expose unit media, and media playlist routes are active. The teacher launch protocol still lacked a direct link to the current unit playlist.

## Decision

Pass the content package into the teacher launch panel and render a `Unit media` shortcut when a playlist exists for the unit.

## Consequences

Teachers can open the unit playlist from the classroom protocol page. The shortcut stays package-driven and does not change progression, Star Dust, or game unlock rules.
