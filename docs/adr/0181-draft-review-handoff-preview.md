# ADR 0181: Draft Review Handoff Preview

Date: 2026-07-13

## Status

Accepted

## Context

Teacher draft editing needs a future path into verifier and human review, but live submission requires persistence, ownership, audio, rights, route, and approval workflows.

## Decision

Add a read-only draft review handoff preview to `/teacher/authoring/draft-sample-publisher-l1-u1`.

The preview shows schema, source lineage, audio coverage, rights/version, route/activity, and approval packets while keeping review submission blocked.

## Consequences

Teachers can see what review will require without implying that draft submission, publish, or student assignment is live.
