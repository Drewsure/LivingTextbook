# ADR 0056: Media Rights Readiness Gate

Date: 2026-07-09

Status: accepted

## Context

Audio and video are central to the white-label Living Textbook product. Source review and local bundle panels mention media, but rights readiness needs its own gate.

## Decision

Add media rights readiness records and panel.

## Implications

Future pilots must handle:

- media owner,
- usage scope,
- game-background permission,
- offline/local bundle permission,
- missing file fallback,
- and blocked media.
