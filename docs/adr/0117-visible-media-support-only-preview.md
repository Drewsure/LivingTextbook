# ADR 0117: Visible Media Support-Only Preview

## Status

Accepted

## Context

Media playlist routes emit support-only event metadata, but visible demo surfaces should also explain what the events mean.

## Decision

Update playlist event previews and route verification so media controls show support-only event wording.

## Consequences

- Demo routes better explain the multimedia platform.
- Route checks protect the support-only wording from accidental removal.
- Media remains core to engagement without being mistaken for mastery.
