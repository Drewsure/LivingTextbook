# ADR 0080: Teacher Session Monitor Game Audio Coverage

## Status

Accepted

## Context

Assigned game audio coverage now appears in package, publish, assignment, rollout, and preflight layers. The teacher session monitor needed to show the same coverage in the report-facing surface.

## Decision

Add audio-covered game mode metadata and audio gap labels to the teacher session monitor.

## Consequences

Teachers can see audio coverage alongside assigned game modes during session review. This reinforces audio-first learning without adding storage, raw audio handling, or premium features.
