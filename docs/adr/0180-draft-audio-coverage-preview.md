# ADR 0180: Draft Audio Coverage Preview

Date: 2026-07-13

## Status

Accepted

## Context

Teacher draft editing can change learner-facing text. For young learners and English learners, audio support is a core requirement, not a polish layer.

## Decision

Add a draft audio coverage preview to `/teacher/authoring/draft-sample-publisher-l1-u1`.

The preview shows term audio, sentence audio, instruction audio, and the audio regeneration requirement before student use.

## Consequences

Teacher authoring remains audio-first. Live draft save and review submission must eventually connect edited text to reviewed target-language audio or approved fallback voices before assignment.
