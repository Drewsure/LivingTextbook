# ADR 0215: Teacher Dry-Run Rehearsal Preview

Date: 2026-07-15

## Status

Accepted

## Context

The pilot launch checklist names a teacher classroom dry run as a required stage, but a vague dry-run requirement is not enough for partner pilots. Teachers need a concrete script for checking routes, audio, games, media, reporting, support-language limits, and local fallback expectations before children use the package.

## Decision

Add a `Teacher dry-run rehearsal preview` to `/teacher/intake`.

The rehearsal derives from the pilot launch checklist, pilot evidence packet, and pilot handoff package. It gives teachers a route-by-route rehearsal plan while preserving a hard boundary around student launch, real learner data, report export, evidence upload, and pilot approval.

## Consequences

- Partner pilots get a practical pre-classroom test script.
- Route, game, audio, media, support-language, report, and local fallback checks become visible before live workflows.
- The foundation remains safe because the rehearsal is dry-run evidence only and cannot approve or launch a classroom pilot.
