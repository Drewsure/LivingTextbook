# ADR 0386: AI Generated Package Writer Harness Implementation Decision

Date: 2026-08-11

Status: Accepted

## Context

The generator route already names package writer test harness plans and implementation proposals, but there was no visible Codex decision preview between "proposal exists" and "future harness code might be approved."

That gap matters because package writer harness code is close to routes, playlists, local bundles, assignments, rollback, and future evidence upload workflows.

## Decision

Add a review-only package writer harness implementation decision preview to the teacher generator route.

The preview names required evidence, file scope rules, decision options, blocked actions, next records, and support-language boundaries while showing that no decision is recorded.

## Consequences

- Harness implementation remains blocked until a future explicit Codex decision and storage contract exist.
- The page can distinguish "return for more evidence," "reject scope," and "approve dry-run harness scope only" without creating approval behavior.
- MiniStar keeps English as the target-language assembly trigger and keeps hiragana Japanese support support-only.
- No writer, route, playlist, local bundle, assignment, evidence upload, or production QR mutation can be inferred from the decision preview.
