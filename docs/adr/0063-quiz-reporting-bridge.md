# ADR 0063: Quiz Reporting Bridge

## Status

Accepted

## Context

Quiz is now playable through `/quiz/[code]`. Teacher visibility needs to follow the same reporting pattern used by existing game routes.

## Decision

Add Quiz to the sample teacher monitor progression and event stream.

## Consequences

Quiz is now visible in reporting as a normal selection-engine completion. This keeps later arcade selection skins aligned with a shared reporting contract.
