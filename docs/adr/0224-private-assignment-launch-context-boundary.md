# ADR 0224: Private Assignment Launch Context Boundary

Date: 2026-07-15

## Status

Accepted

## Context

Private assignment links are the first safe sharing path for teachers, but they are still preview links until live classroom launch policy, persistence, reporting, roster identity, and access controls are implemented.

## Decision

Add the controlled-practice launch context card to private assignment routes.

The card states that private assignment routes are controlled assignment practice, that target language unlocks progress, that support language and media are support only, and that no production student accounts are being used.

## Consequences

- Assignment routes now match direct launch and front-door routes.
- Teachers can preview private assignment sharing without implying live classroom launch.
- This does not enable assignment persistence, production accounts, report export, real learner data collection, or public sharing.
