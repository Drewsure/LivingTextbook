# ADR 0100: Student Unit Media Shortcut

## Status

Accepted

## Context

The platform now has active media playlist routes for MiniStar and the sample publisher. Student launch pages still did not expose the package playlist.

## Decision

Pass the content package into the student launch flow and render a unit media shortcut card when a playlist exists for the unit.

## Consequences

Media becomes visible in the classroom path while preserving the target-language progression gate. The card links to reviewed playlist metadata and does not trigger Star Dust, mastery, or game unlocks.
