# ADR 0091: Focused Training Demo Shortcut

## Status

Accepted

## Context

Training Academy now supports `?focus=` routing. If the teacher launch page only links the default recovery lane, reviewers may miss the focused route behavior.

## Decision

Add a `Training: Sentences` shortcut to the teacher launch demo route list.

## Consequences

Focused recovery routing is easier to verify without creating new pages or production QR contracts.
