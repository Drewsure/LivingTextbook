# ADR 0451: Assignment Rollout Generated Evidence Summary

Status: Accepted

Date: 2026-08-28

## Context

Assignment rollout plans now link generated-package assignment handoff evidence packets. The panel needs a quick summary so teachers and tenant admins can see generated evidence coverage before reading individual plan cards.

## Decision

Add a generated-package evidence count to the assignment rollout summary metrics.

## Consequences

- The rollout surface is easier to scan for tenant demos and internal review.
- The metric is informational only and cannot schedule classes, activate assignments, approve evidence, or write storage.
- Detailed source evidence packet ids remain visible inside each rollout plan.
