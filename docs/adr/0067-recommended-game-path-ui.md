# ADR 0067: Recommended Game Path UI

## Status

Accepted

## Context

The platform now has active routes for Memory Match, Quiz, Sentence Builder, and Speak It. Launch sessions support multiple recommended modes, but the student UI only exposed the first one.

## Decision

Expose all recommended modes as a route card after entry practice, while keeping Memory Match as the embedded next game.

## Consequences

The student-facing flow better reflects the platform progression without requiring a full assignment backend.
