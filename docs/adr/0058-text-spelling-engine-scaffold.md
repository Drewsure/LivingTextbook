# ADR 0058: Text-Spelling Engine Scaffold Before Sentence Builder Skin

Date: 2026-07-09

Status: accepted

## Context

The project has a playable pairing example and a selection engine preview. Sentence Builder is the next important parent-engine direction because it supports syntax and upper-level growth.

## Decision

Add a Sentence Builder preview as the first text-spelling engine scaffold.

## Implications

Playable implementation and premium visuals remain separate next steps.

The scaffold defines payload mapping, tile ordering, audio text, standard events, and scoring profile before visual polish or Phaser skins.
