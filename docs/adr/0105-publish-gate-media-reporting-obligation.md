# ADR 0105: Publish Gate Media Reporting Obligation

## Status

Accepted

## Context

Media playlist routes, student/teacher shortcuts, and teacher monitor media engagement are now active scaffolds. The publish gate still needed to name the obligations that make media safe for a real pilot.

## Decision

Update the package publish gate so media rights and teacher report policy require reviewed playlist routes, bundle decisions, and support-only media engagement reporting.

## Consequences

The release surface now reflects the multimedia product promise without overclaiming readiness. Media remains important and reportable, but cannot become a progression shortcut.
