# ADR 0655: Match Up Canonical Integration

**Status:** Accepted  
**Date:** 2026-09-13

## Decision

Match Up is promoted into the canonical DOM game integration set. It must use
the shared pairing engine boundary, route shell, progression adapter, audio
event contract, deterministic replay identity, and completion validation
boundary.

## Rationale

Match Up is the clearest bridge between listening and visible vocabulary
recognition. Promoting it beside Memory Match and Label It verifies that the
pairing engine can support different card roles without duplicating reporting,
audio, scoring, or completion semantics.

## Boundaries

- Source prompts and target cards are derived from reviewed vocabulary only.
- Incorrect matches remain visible in evidence but do not earn mastery credit.
- Audio supports the learner and evidence stream but never unlocks progress.
- No AI generation, live persistence, random reward, or Phaser promotion is
  enabled by this slice.
