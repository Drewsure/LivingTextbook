# ADR-0408: Active Game Replay Route Links

Date: 2026-08-21

## Status

Accepted.

## Context

The active game replay checklist needs to be useful as a teacher/admin QA surface, not only a policy description.

## Decision

Render active replay route paths as clickable local links and verify representative links on `/teacher/intake`.

## Consequences

- Positive: Reviewers can move quickly from evidence expectation to active route.
- Positive: Future outside prototype comparisons can use the checklist as a navigation hub.
- Constraint: Links do not imply route approval beyond the current reviewed demo state.

See `docs/decision-register/DR-479-active-game-replay-route-links.md`.
