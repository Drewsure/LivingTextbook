# ADR 0054: Assignment Rollout Gate Before Scheduled Pilot

Date: 2026-07-09

Status: accepted

## Context

Teacher assignment readiness defines class launch plans, but it does not fully answer whether an assignment can be scheduled for a real pilot.

## Decision

Add assignment rollout plans and a teacher intake panel.

## Implications

The project now distinguishes:

- demo-preview,
- blocked rollout,
- ready-to-schedule,
- pilot-ready.

This keeps sales/pilot conversations realistic while preserving confidence.
