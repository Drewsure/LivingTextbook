# ADR-0038: Pilot Handoff Package

Date: 2026-07-03

## Status

Accepted

## Context

Living Textbook now has enough white-label scaffolding to discuss a partner pilot: second tenant routes, front-door entry, teacher monitor, multimedia package structure, roster identity, and policy/persistence gates. Without a handoff view, it is too easy to either understate the value or overpromise production readiness.

## Decision

Represent the first partner pilot as a handoff package on the teacher/admin intake route. The package lists routes, assets, human decisions, owners, cost impact, and explicit handoff notes.

## Consequences

- Partner conversations can be grounded in a visible route and asset map.
- The project can quote an 8-12 week testable pilot while still showing blockers.
- The hosted PWA remains the recommended first pilot path for cost efficiency.
- Closed/local deployment remains in scope but does not become the default first cost center.
- AI Tutor remains optional premium scope.
