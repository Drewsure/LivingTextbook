# ADR 0086: Progress Event Taxonomy Panel

## Status

Accepted

## Context

Progress events are becoming the backbone of teacher reports, Training Academy triggers, game completion, multimedia engagement, and future persistence. A hidden event union is not enough for a white-label product that will involve outside agents, tenant package review, and backend migration planning.

## Decision

Create sample progress event taxonomy data and render it on the teacher/admin intake page. Each event declares whether it is progress-affecting, report-only, or support-only, with blocked misuse notes.

## Consequences

Backend and reporting work can reference an explicit event map. The admin UI reinforces that route guidance, support language, and background media do not drive mastery.
