# ADR 0654: Label It Canonical Integration

**Status:** Accepted  
**Date:** 2026-09-13

## Decision

Label It is promoted into the canonical DOM game integration set. It must use
the shared pairing engine boundary, route shell, progression adapter, audio
event contract, deterministic replay seed, and completion validation boundary.

## Rationale

Label It is the first canonical image-aware path. Promoting the interaction
while keeping uploads review-only proves that a labelled diagram can be
integrated without allowing unreviewed tenant assets to become student-facing
content or changing the platform's storage boundary.

## Boundaries

- Anchors and labels are derived from reviewed unit content.
- Incorrect placements remain visible in evidence but do not earn mastery
  credit.
- Audio supports the learner and evidence stream but never unlocks progress.
- No live upload, asset promotion, AI generation, persistence, random reward,
  or Phaser promotion is enabled by this slice.
