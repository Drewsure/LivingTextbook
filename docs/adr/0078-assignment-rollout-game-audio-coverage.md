# ADR 0078: Assignment Rollout Game Audio Coverage

## Status

Accepted

## Context

Assigned game audio coverage now appears in package, assignment, and session layers. The rollout layer still needed to expose it before a draft is scheduled.

## Decision

Add `game-audio-coverage` gates to assignment rollout plans.

## Consequences

Teachers and admins can see game audio coverage before scheduling a pilot. The local companion path stays honest about offline audio coverage still needing review.
