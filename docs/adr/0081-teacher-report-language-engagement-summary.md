# ADR 0081: Teacher Report Language Engagement Summary

## Status

Accepted

## Context

The platform requires target-language engagement to drive progression while support language remains comprehension support. Sample events already captured English audio heard and support-language taps, but the report summary did not surface them clearly.

## Decision

Add visible report metrics for English audio heard, support taps, and support unlock events.

## Consequences

Teachers can see support-language use without confusing it with progression. This keeps the foundation aligned with young learner audio-first rules and support-language restrictions.
