# ADR 0093: Active Route Matrix Panel

## Status

Accepted

## Context

The active route verification list is maintained in documentation. As the route set grows, the teacher/admin review surface should also show representative active routes so demos and QA checks are easier to run.

## Decision

Add sample active route matrix data and render it on `/teacher/intake`.

## Consequences

Route QA becomes more visible without changing route contracts or QR readiness rules. The panel remains scaffold/admin guidance.
