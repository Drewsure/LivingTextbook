# ADR 0151: Competitive Feature Coverage Matrix

## Status

Accepted

## Context

Wordwall-style products set useful teacher expectations: fast activity creation, many templates, assignment links, printables, activity switching, customization, sharing, embedding, community resources, analytics, and automated testing. Living Textbook should learn from these expectations without turning the foundation build into unfocused competitor copying.

## Decision

Add `docs/COMPETITIVE_FEATURE_COVERAGE_MATRIX.md` and expose a compact competitive coverage panel on `/teacher/intake`.

## Consequences

- Curated activity pathways become the preferred answer to template switching.
- Printable worksheet/PDF output is recorded as planned, not ignored.
- Private tenant libraries come before public community libraries.
- Public community sharing is treated as a white-label risk until moderation, copyright, privacy, and quality controls exist.
- Japanese-as-target-language is recorded as a plausible white-label opportunity separate from Japanese assist language.
- Future teacher authoring and activity conversion work has a strategy document to consult before implementation.
