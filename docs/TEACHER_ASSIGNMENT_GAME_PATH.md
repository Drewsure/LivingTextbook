# Teacher Assignment Game Path

## Purpose

Teacher assignment plans now show the reviewed game modes assigned to a launch package. This keeps teacher/admin readiness aligned with the current student game path.

## Current Game Path

Sample assignments include:

- Flashcards
- Memory Match
- Quiz
- Sentence Builder
- Speak It

## Boundary

This is still a static scaffold. Real classroom assignment choices need persisted launch-session settings before teachers can save custom game paths for a class.

## Acceptance Standard

- `/teacher/intake` shows assigned game modes for each sample assignment plan.
- The assigned modes include Quiz and Sentence Builder.
- The panel does not imply that teachers can persist custom assignment settings yet.
- Premium or policy-controlled modes remain governed by assignment controls.
